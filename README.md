# Sitara Emporium

This is a ready-to-publish website. It has a shopping bag and WhatsApp checkout to **0330 1339004**.

## Change a price

1. Open `script.js` on GitHub.
2. Find the ring you want in the `products` list at the very top.
3. Change `price: ''` to a number, for example `price: 8500`.
4. Click **Commit changes**. Vercel publishes the update automatically.

## Add a product later

1. Upload its image in GitHub to the `images` folder.
2. Copy one full product line in `script.js` and update its `id`, `title`, `image`, and `alt`.
3. Commit the update. The site will redeploy automatically.

No card payment is collected on this version. The checkout sends the selected pieces and customer details to WhatsApp, where you confirm price, size, delivery and payment.
